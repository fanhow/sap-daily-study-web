6.2 鑰匙、鑰匙櫃與模擬單線圖

安全鎖

在簽發工作許可證（PTW）前，以及適任人員（CP）開始作業前，凡可行之處，須在所有隔離點裝設安全鎖與注意標示，並在所有施加電路主接地（Circuit Main Earths）的地點裝設安全鎖。在簽發測試許可（SFT）前，凡可行之處，須在所有隔離點裝設安全鎖與注意標示，並在所有施加附加接地（Additional Earths）的地點裝設安全鎖／工作鎖。

資深授權人員（SAP）配合簽發工作許可證（PTW）或測試許可（SFT）而正在使用的安全鎖，其鑰匙須放入安全鑰匙箱。

不使用時，安全鎖及鑰匙須保管於工作鑰匙櫃（Working Key Cabinet）。

安全鑰匙箱

安全鑰匙箱須配備兩個鎖，每個鎖只能有一把鑰匙；其中一把標示「Safety Key Box - Competent Person」（安全鑰匙箱－適任人員），另一把標示「Safety Key Box — Senior Authorised Person」（安全鑰匙箱－資深授權人員）。其配置須確保兩個鎖均已開啟，才可取用箱內物品。

每個已任命資深授權人員（SAP）的場址，其安全鑰匙箱配置數量須由授權工程師（AE）決定。

每個安全鑰匙箱須標示場址名稱及序號，以確保在該場址內可明確識別。

使用時，每個安全鑰匙箱僅可存放與單一工作許可證（PTW）或單一測試許可（SFT）相關的安全鎖鑰匙。

裝設安全鎖後、簽發工作許可證（PTW）或測試許可（SFT）前，須將所有安全鎖的鑰匙放入安全鑰匙箱，並將箱上的兩個鎖鎖妥。簽發許可證或測試許可時，值勤 SAP 須保管 SAP 鑰匙，並將 CP 鑰匙交給適任人員（CP）。

適任人員（CP）須保管 CP 鑰匙，直至工作許可證（PTW）或測試許可（SFT）註銷為止。

不使用時，安全鑰匙箱的鑰匙須保管於工作鑰匙櫃。

鑰匙板系統（Key Plate System）

以下各處配置的每個鎖均須有一把鑰匙：

高壓開關設備。

(ii) 每座變電站、備用發電機組機房，以及任何含有高壓設備的建築物、建築物局部區域或圍籬區域的入口。

每座變電站的鑰匙須固定於尺寸適當的鑰匙板上；鑰匙板須標示鑰匙所屬之變電站、建築物或設備項目的識別資料，或各把鑰匙的預定用途。

鑰匙管制箱 [英文OCR不清：Key Box Control Box]

須在工作鑰匙櫃旁安裝一個配有密碼鎖的鑰匙箱。資深授權人員（SAP）／授權人員（AP）的鑰匙，未由值勤 SAP／AP 使用時，須鎖放於此箱內。此箱內不得存放其他鑰匙。

該系統或裝置所任命的所有資深授權人員（SAP）／授權人員（AP），均須知道該鎖的密碼。其他任何人均不得知道該密碼。密碼鎖設定須每年更換，或只要懷疑設定已洩漏時即須更換。
